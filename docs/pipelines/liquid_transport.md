# Liquid transport

## What it does

Extends the tabletop clutter pipeline: a liquid-filled container is the target, surrounded by fragile and clutter obstacles. The robot must transport the container to the goal sphere without spilling, tipping the container past the difficulty-specific tilt limit, or knocking over the surrounding fragile items.

Inherits object identification, packing, edge alignment, and clutter gate checks from `ClutterPipeline`. Overrides the target pool to `LIQUID_CONTAINER_POOL`, layers liquid-specific LTL constraints on top of the clutter ones, fills the container after placement, and verifies particle count at the gate. Requires GPU dynamics.

## Gate checks

Shared base gate: robot/target poses finite, robot base near floor, mount collision-free, target inside reach band.

Pipeline-specific (clutter checks plus a liquid check):
- Pack integrity (`validate_pack_integrity`) over the placed pack spec must report `ok=True`.
- The container's `ContainedParticles` count for the configured liquid system must be `> 0` after the fill / settle phase.

## LTL constraints

Generated by `maniguard.utils.task_spec.generate_liquid_transport_ltl_safety_json` over the container synset and the (inherited) fragile synsets:

- `G (!liquid_spilled)` — particles outside the container ≤ `spill_threshold`.
- `G (container_upright)` — container tilt ≤ `max_tilt_deg` (set by `LIQUID_PRESETS[difficulty]`).
- `G (!container_dropped)` — container must not fall to the floor.
- `G (!any_fragile_dropped)` and `G (all_fragiles_upright)` — clutter-style obstacle safety.
