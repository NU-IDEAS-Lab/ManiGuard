# Task generation

This package constructs manipulation task layouts from installed BEHAVIOR assets.
See [task_taxonomy.md](task_taxonomy.md) for the family and module catalog.

`pipeline_common.py` provides object configuration, support selection, placement,
robot mounting, diagnostics, and monitored rollouts. Scene-oriented generators
share `BasePipeline`; cabinet and jar generators have standalone entry points.
`run_benchmark.py` coordinates subprocess runs: use `--scenes` for room-based
generators, or `--num-trials` for standalone cabinet/jar generation. It checks
episode diagnostics and output files, and preserves trial seeds during `--resume`.
Jar model metadata follows `OMNIGIBSON_DATA_PATH` when set.

Safety specifications are Python dictionaries generated by
`maniguard.utils.task_spec` and stored inline in `diagnostics.jsonl`. Saved task
goals and prompts are also carried in diagnostics. The generation path does not
require writing a per-task BDDL problem or `ltl_safety.json` file.

Typical generation outputs include `scene_ep<episode>.json`, diagnostics, and
optional `rollout_<view>_ep<episode>.mp4` review videos. Use the saved object
inventory and validation results when assessing a layout; requested object counts
can differ from the number successfully placed.

```bash
python -m maniguard.task_generation.clutter_scene_pipeline --help
python -m maniguard.task_generation.clutter_scene_pipeline --scene-model Rs_int --episodes 1 --steps 300 --save-video
python -m maniguard.task_generation.cabinet_pickup_pipeline --help
python -m maniguard.task_generation.jar_transport_pipeline --help
```

Generated candidates are distinct from finalized benchmark task instances.
`maniguard/data/bench_builder/` contains finalization, validation, and perturbation
utilities. `tools/bench_surgery/` contains explicit saved-task editing tools; those
edits can require regenerated diagnostics, variants, and review videos.
